# HOPE

Android-приложение: генератор и проверка Telegram username (t.me + Fragment) прямо с устройства.
Kotlin, Jetpack Compose, Room, Coroutines, OkHttp. Без сервера.

Сборка: `bash scripts/build.sh` (Codespaces) или Codemagic (`codemagic.yaml`).
APK: `HOPE.apk` / `app/build/outputs/apk/release/app-release.apk`.
