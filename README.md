# Hope

Поиск свободных username в Telegram: генерация, проверка на t.me и Fragment, отправка находок в твоего бота. Тёмная тема, чёрный фон. Логика взята из "Kataract.py" созданный мной (скачать скрипт можно в тгк: @limcatalog

## Как собрать APK в Codespaces

1. Создай пустой репозиторий на GitHub, загрузи туда содержимое этого архива (или распакуй zip прямо в Codespace).
2. Открой репозиторий: Code → Codespaces → Create codespace.
3. В терминале:
   ```
   ./build.sh
   ```
   Первая сборка 5–10 минут: скачиваются Android SDK и Gradle.
4. APK будет в `dist/Hope.apk`. Правый клик по файлу в Explorer → Download, затем установи на телефон (разреши установку из неизвестных источников).

Альтернатива без терминала: вкладка Actions → Build APK → Run workflow, готовый файл лежит в Artifacts.

## Как это работает

- Имена генерируются и сразу уходят на проверку, без ожидания пачки.
- Если подключён бот и включено «Слать находки в бота», каждая находка отправляется автоматически. Первая уходит сразу, остальные собираются не дольше секунды.
- Бот подключается в приложении: токен из @BotFather, потом Start в боте и «Привязать».
- Пока идёт поиск, экран не гаснет. Если свернуть приложение, Android может приостановить процесс.
- Сохранённые файлы: `Android/data/com.hope.app/files/` (свободные, Fragment, сгенерированные).
